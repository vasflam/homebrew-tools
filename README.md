# Vasflam Tools

## How do I install these formulae?

`brew install vasflam/tools/<formula>`

Or `brew tap vasflam/tools` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "vasflam/tools"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
